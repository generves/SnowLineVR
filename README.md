## 项目简介

《雪线之上》是一款面向冰雪运动的 VR 急救实训系统。学员戴上头显后，会以第一人称站在雪道现场，面对一名膝关节扭伤的伤员，用手柄完成从环境安全评估到交接伤员的完整流程。

训练流程固定为五步：

| 步骤 | 内容 | 关键动作 |
|---|---|---|
| 1 | 环境安全评估 | 观察上方雪道，放置警示牌（地面有蓝色落位区提示） |
| 2 | 制动与固定 | 从医疗箱取出夹板，贴合小腿并锁定 |
| 3 | RICE 现场处置 | 冰袋冷敷 + 绷带加压 |
| 4 | 呼救与信息报送 | 拿起手机，对准路牌编号完成报送 |
| 5 | 交接伤员 | 引导伤员躺上担架，扣下床头板移交 |

训练结束后自动生成评估报告，包含总分、等级、时间轴回放与按优先级排序的改进建议。

## 技术要点

### 双轨判定

步骤对错只影响评分；**道具在错误时机作用于伤员身上才影响生理数值**。两条轨道互不干扰，用来还原"操作失误导致生理恶化"的真实因果，而不是做一道对错选择题。

### 生理驱动模型

伤员的心率不是写死的，而是由疼痛、体温和急救进度推导：

```
HR = 88 + 疼痛 × 5 + (36.4 − 体温) × 20 − (当前步骤数 − 1) × 6
```

- **体温**：非线性失温，越冷越难降（36.4℃ 时 0.008℃/s，趋近 32℃ 时归零）
- **冰袋**：错误时机使用 → 每次体温 −0.2℃
- **夹板 / 绷带**：错误时机使用 → 疼痛 +1.00 递减至 +0.40，10 次合计 +7.0
- **保温毯**：体温 < 36℃ 时生效 40 秒，+0.02℃/s、上限 36℃，全局只能用一次
- **疼痛累积到 10 → 训练立即终止**

### 器械物理

- **夹板**：两端对齐肢体端点后锁定（两点刚体约束 + 每帧限幅，防止飞出地图）
- **绷带**：真实骨骼蒙皮，两根骨骼 + 逐顶点 BoneWeight + bindpose 自检，会跟着小腿弯曲

### 伤员表演

17 个状态的动画机，配合三处过渡补偿：切换动画时冻结水平位移（过渡锚定）、躺姿高度对齐、原地转向。避免"每播完一段动画就跳回原点"。

### 教学引导

任务清单（右侧常驻、当前步高亮）+ 地面落位区 + 按需揭示道具（用对道具对应器械才出现）。

## 运行要求

**软件环境**（版本不匹配很可能直接编译不过）：

| 项目 | 版本 |
|---|---|
| Unity | **6000.6.3f1** |
| 渲染管线 | URP 17.6.0 |
| XR 交互 | XR Interaction Toolkit 3.6.1 |
| 输入系统 | Input System（**仅 New**，`activeInputHandler = 1`） |
| 脚本后端 | Mono |

**硬件**：没有头显也能运行 —— 场景里挂了 `XR Device Simulator`，用键盘鼠标模拟双手柄。

**操作方式**：

```
鼠标          转视角 / 左右键对应双手
a d s w q e   左右手柄移动 / 旋转
h r t u v x c z 1 2 3 tab space   手柄按键
左Shift / 左Ctrl / Esc / \        修饰键与菜单
```

（项目内自定义功能键：F1/F2/F3 = 交互，F6/F7/F8 = 使用模式，F10 = 日志开关）

## 团队成员上手

### 1. 克隆

```bash
git clone <本仓库地址>
```

### 2. 用 Unity Hub 打开

必须用 **6000.6.3f1** 打开。首次打开会重建 `Library/`，需要几分钟。

### 3. 配置 Unity 的智能合并工具（强烈建议，否则改场景必然冲突）

```bash
git config merge.unityyamlmerge.name "Unity SmartMerge"
git config merge.unityyamlmerge.driver "\"<Unity安装路径>/Editor/Data/Tools/UnityYAMLMerge.exe\" merge -p %O %B %A %A"
```

Windows 默认路径形如：
`C:/Program Files/Unity/Hub/Editor/6000.6.3f1/Editor/Data/Tools/UnityYAMLMerge.exe`

### 4. 约定

- **不要提交 `Library/`、`Builds/`、`Logs/`**（已在 `.gitignore` 中排除）
- 改场景前先 `git pull`，改完立刻提交；`SampleScene.unity` 是多人冲突高发区
- 新增素材请同步更新根目录的 `素材来源与授权记录.md`
